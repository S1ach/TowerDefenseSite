# Графика Kenney

Источник: [Kenney Tower Defense Kit 2.1](https://kenney.nl/assets/tower-defense-kit), также доступен на [itch.io](https://kenney-assets.itch.io/tower-defense-kit).
Автор: Kenney. Лицензия: CC0 1.0. Оригинальный текст поставляется в `public/models/kenney/License.txt`.

В проект включены только используемые GLB, три PNG-превью оружия и общий атлас `Textures/colormap.png`. GLB ссылаются на этот атлас по относительному пути: переносить модели нужно вместе с папкой Textures. Исходные файлы моделей не изменены.

| Объект игры | Модель |
| --- | --- |
| Пулемёт (`machine`) | `weapon-turret` |
| Пушка (`cannon`) | `weapon-cannon` |
| Баллиста (`sniper`) | `weapon-ballista` |
| Основания уровней 1–3 | `tower-round-bottom-a/b/c` + `tower-round-top-a` |
| Тарелка / перехватчик / тяжёлый НЛО | `enemy-ufo-a/b/d` |
| Пули / ядра / стрелы | `weapon-ammo-bullet/cannonball/arrow` |
| Остров, поле, дорога, портал, крепость, деревья, камни | процедурно из примитивов (`IslandTerrain.tsx`), модели не используются |

`KitModel.tsx` загружает модели через useGLTF и разделяет геометрию/атлас между экземплярами. Для строительного предпросмотра копируются материалы. НЛО и боеприпасы используют InstancedMesh. Файлы `tile*`, `spawn-round`, `tower-round-middle-a`, `tower-round-roof-a` и `detail-*` больше не загружаются и могут быть удалены из `public/models/kenney`. Кольца выбора, полосы здоровья, частицы и диагностические линии остаются процедурными элементами интерфейса.

Уровень земли — Y=0; локальные модели направлены по +Z. Основание башни неподвижно, оружие вращается вокруг Y. Числовой баланс, маршрут, идентификаторы типов и формат сохранения сохранены.

Для редактирования в Blender: импортируйте GLB с лежащей рядом папкой Textures, внесите изменения и экспортируйте glTF 2.0 (.glb), сохранив масштаб, начало координат и направление. Соответствие моделей находится в `KitModel.tsx`, `Towers.tsx` и `Units.tsx`.
